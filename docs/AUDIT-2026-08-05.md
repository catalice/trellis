### Live bugs (small, real)

1. **High-priority tasks sort last** — `domain_focus_repo.py:278`
   `ORDER BY due_at NULLS LAST, priority DESC` on a TEXT column → alphabetical
   DESC = medium, low, high. Every undated task listing puts high priority bottom.
2. **Timestamps mislabelled "UTC"** — `domain_focus_tool.py:1117` `_fmt_datetime`
   appends "UTC" to datetimes that are Madrid-local (set_reminder attaches user tz).
   Receipt for an 18:00 reminder reads "18:00 UTC" — invites the model to "correct".
3. **save_preferences can silently wipe prefs** — `core_profile.py:268` replaces the
   whole domain blob; tool description doesn't say merge. House prefs aren't in
   context unless that house routed → save in the wrong turn = old prefs gone.
4. **Summariser fires first turn after every restart** — `core_assembler.py:280`
   `_last_summarised` is in-memory (resets to 0) vs lifetime `turn_count`.
   Related: `PostgresConversationHistory.prune()` has no callers →
   `conversation_turns` grows unboundedly.
5. **docker-compose env_file `../Trellis/.env`** — only resolves on case-insensitive
   macOS; on Linux silently loads nothing (`required: false` masks it).

`.env` has `ANTHROPIC_MODEL=claude-sonnet-4-6` — previous-generation Sonnet.
Current Sonnet is `claude-sonnet-5`: near-Opus quality on conversational/agentic
work, same price class ($3/$15 per MTok; intro $2/$10 through 31 Aug 2026).
Trellis's calls are clean for a swap (no budget_tokens, no sampling params, no
